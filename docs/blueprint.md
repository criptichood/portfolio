# **App Name**: Criptic Digital

## Core Features:

- AI-Powered Content Generation: Generate relevant and engaging website copy, blog posts, and project descriptions using AI. Tool to tailor content to different tones and audiences.
- Service Display: Showcase services (AI Website Development, System Maintenance, etc.) with icons and descriptions.
- Project Portfolio: Display a portfolio of completed projects with images, descriptions, and links to live demos or GitHub repositories (github.com/criptichood).
- Contact Form: Allow visitors to send messages via a contact form. All inquiries are sent via email.
- Social Media Links: Link to social media profiles, including LinkedIn, X/Twitter, GitHub, Linktree, and WhatsApp.
- Responsive Layout: Ensure the website is responsive and displays correctly on all devices.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to reflect a tech-oriented, professional aesthetic.
- Background color: Very light gray (#F5F5F5) to ensure readability and a clean look in a light color scheme.
- Accent color: Vibrant purple (#9C27B0) to highlight call-to-action buttons and important elements, creating visual interest.
- Font pairing: 'Space Grotesk' (sans-serif) for headings and short body text; 'Inter' (sans-serif) for longer blocks of body text.
- Use Lucide-react icons for a clean, modern, and consistent visual language.
- Implement a grid-based layout to ensure responsiveness and maintain a structured visual hierarchy.
- Incorporate subtle fade and slide animations using Framer Motion to enhance user experience without overwhelming the interface.
